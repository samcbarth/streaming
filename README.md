# streaming.samcbarth.com (Streaming Price Check)

Affiliate-funded, research-based guide to US streaming services and devices. Part of the samcbarth.com network; shared rules live in `C:\SamSites\NETWORK.md`.

Plain static HTML generated by `build.py` (Python 3.12, Pillow for share images). No framework, no server needed in production. GitHub Pages serves the repo root from `main`.

## Run locally

```
python build.py            # regenerate every page, feeds, sitemap, images
python scripts/check.py    # link check, em dash / emoji check, JSON-LD, meta, feed shape
python -m http.server 8824 # preview at http://localhost:8824
```

The `streaming` entry in `.claude/launch.json` (and in `C:\.claude\launch.json`) starts the same preview on port 8824.

## What is on the site

| Section | Source file | Pages |
|---|---|---|
| Reviews (`/reviews/<slug>/`) | `data/services.json` | 12 services, Review JSON-LD, plan tables with source link + "last checked" date |
| Comparisons (`/compare/a-vs-b/`) | `data/compare.json` | 10 head-to-head pages |
| Best of (`/best/<slug>/`) | `data/best.json` | sports, kids, cheapest, live TV |
| Devices (`/devices/<slug>/`) | `data/devices.json` | Roku, Fire TV, Apple TV 4K, Google TV Streamer, with "Check price on Amazon" buttons |
| Calculator (`/calculator/`) | built from `data/services.json` | cord-cutting cost calculator |
| News (`/news/`) | `news/stories/*.json` | "The Stream Desk", JSON Feed at `/news/feed.json`, RSS at `/rss.xml` |
| Required pages | `build.py` (`build_static`) | About, How we research, Contact, Affiliate disclosure, Privacy, Terms |

## How to add or update content

- **Prices changed:** edit the plan in `data/services.json`, update `"checked"` at the top to today's date (every "last checked" line and the calculator use it), then `python build.py`.
- **New news story:** copy any file in `news/stories/`, change `slug`, `title`, `date_published` (YYYY-MM-DD), `summary`, `body` (paragraphs), `tags`, `source` (name + URL, required), `related` (internal paths). Run the build. Rules: real, verifiable events only, original wording, link the source, at most one short attributed quote.
- **New comparison:** add `{a, b, answer, points}` to `data/compare.json` using service slugs.
- **New service:** add an object to `data/services.json` and a matching key in `AFFILIATE` in `assets/config.js`.
- Share images in `assets/img/` are generated once; delete a `.webp` to regenerate it.
- The build refuses to write a page that contains an em dash.

## Where config ids go

All in `assets/config.js`, applied in the browser, so no rebuild is needed:

- `AMAZON_TAG`: Amazon Associates tag. Empty = every "Check price on Amazon" button stays hidden.
- `AFFILIATE['<service>']`: full tracking URL per service. Empty = the button links to the official site with no tracking.
- `HUBSPOT_FORM_ID` (portal 20693956 is prefilled) and/or `CONTACT_EMAIL` for the Contact page. **Both are empty right now**, so the Contact page says the form is being set up. Fill one before applying to any program.
- `ADSENSE_CLIENT`: kept for consistency; this affiliate site places no ad slots. `ads.txt` lives at the root domain samcbarth.com (HubSpot), not on this subdomain.
